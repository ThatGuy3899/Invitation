# Invitation — Yudit

A personalized copy of the interactive date invitation website for Yudit.

- **Live site (once GitHub Pages is enabled):** https://thatguy3899.github.io/Invitation/
- **Source:** [Original Date_Invitation repository](https://github.com/ThatGuy3899/Date_Invitation)
- **Hosting:** GitHub Pages, from the `main` branch and `/ (root)` directory
- **Responses:** Formspree (the same endpoint as the original, but submissions include `invitation_for: Yudit` and Yudit-specific email subjects)

All date plans, optional claw machine, memes, maps, calendar links, and responsive design are preserved.
